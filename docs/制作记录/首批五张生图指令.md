# 《梦境回声》首批五张生图指令

## 使用方式

1. 把当前的 PNG 风格参考图上传给生图软件。
2. 将下面的“完整命令”整体复制进去。
3. 如果软件支持分步生成，先生成第 1～4 张，再把第 1～4 张作为角色一致性参考生成第 5 张。
4. 所有角色必须保持同一批次的画风、脸部特征、服装材质、光照方向和色彩关系。

## 完整命令

```text
请以我上传的 PNG 作为“画风参考图”，不要复制参考图中的具体人物或构图，只参考它的笔触、色彩、光影、细节密度和整体氛围。

项目类型：
《梦境回声》——梦境题材 2D 回合制肉鸽探索游戏。

统一世界观：
人类集体梦境正在崩坏，负面情绪会凝结成心魔。入梦师进入梦层，净化心魔、救出梦魂，并在逐步生成的梦境航线上做出选择。世界观气质是诡异、忧伤、华丽、空旷、带有轻微童话感的梦境冒险，不是写实恐怖，也不是血腥风格。

统一画风：
2D 游戏角色概念设计，半厚涂结合轻赛璐璐，清晰轮廓，适合缩小为战斗卡片。
主色为深蓝、灰紫、墨黑；局部使用暖金、青蓝、青绿色和暗红色高光。
材质表现要有梦境碎片、半透明雾气、漂浮光点、细小符文和不合逻辑的空间错位。
角色要有明确职业轮廓，缩小后仍然容易辨认。
所有角色采用统一的三分之二正面视角，完整显示身体和主要装备。

统一技术要求：
- 一次生成 5 张独立图片，不要生成一张五格拼图，不要把五个人放在同一张图里。
- 第 1～4 张为透明背景全身角色立绘，PNG，竖构图，建议 2:3 比例，建议尺寸 1024×1536 或更高。
- 第 5 张为四人队伍宣传构图，横构图，建议 16:9，建议尺寸 1536×1024 或更高。
- 不要文字、不要技能名称、不要数值、不要 UI、不要卡牌边框、不要水印、不要 Logo。
- 不要现代枪械、科幻机甲、写实血液、过度裸露、夸张肌肉和卡通 Q 版比例。
- 保证手指、武器、脸部、衣物结构完整，避免多余肢体和重复武器。
- 第 5 张中的四名角色必须与第 1～4 张保持脸部、发型、服装和装备一致。

请按下面顺序生成：

【图 1：镇魇武者】
文件名建议：char_warrior_portrait.png
定位：前台，蓄力爆发型近战。
形象：成熟但不苍老的男性入梦师，身穿旧式镇魂重甲，甲片像由黑色梦境碎片和暗红金属拼接而成；肩部挂着被风吹动的镇魇符，腰间有破损的记忆布条。
武器：一把有裂纹的厚重长刃，刀刃内部有暗红色光线，像封印着暴怒心魔。
动作：身体微微前倾，一手持刀，一手压住胸前符印，准备发动蓄力重击。
主色：暗红、铁灰、深棕，局部金色符文。
气质：可靠、沉默、承受压力的前线守卫。
画面要求：完整全身，武器和肩部符纸必须清晰，透明背景，脚下不要绘制场景地面。

【图 2：逐影猎手】
文件名建议：char_ranger_portrait.png
定位：前台，连续射击和追踪。
形象：年轻但目光警觉的女性猎手，穿轻便的深绿色和灰黑色游猎服，衣服边缘像被梦雾侵蚀，肩部有不规则兽纹。
武器：逐影长弓，弓身像弯曲的黑色树枝与月光晶体结合；箭矢带有青绿色光痕。
动作：身体侧转，拉弓瞄准画面外的心魔，身后残留两到三道半透明的影子轨迹。
主色：深绿、墨黑、青蓝，少量银白高光。
气质：敏锐、冷静、行动迅速。
画面要求：完整全身，弓和箭必须完整可见，动作有连续射击感，透明背景，脚下不要场景地面。

【图 3：织梦术士】
文件名建议：char_mage_portrait.png
定位：前台，高费法术和蓄力法术。
形象：年轻的梦境研究者，穿紫黑色长袍，衣摆像翻动的书页和星图；服装上有月相、眼睛和梦境几何符号。
武器：月纹法杖，杖顶悬浮一枚不稳定的月白色晶体，周围环绕橙红色梦火。
动作：一只手托起梦火，另一只手翻动漂浮书页，脚边有小型梦境法阵。
主色：紫黑、月白、橙红梦火、少量金色。
气质：理性、神秘、危险但优雅。
画面要求：完整全身，法杖、梦火、书页和法阵清晰，透明背景，避免过多文字或可读符号。

【图 4：引魂医者】
文件名建议：char_cleric_portrait.png
定位：后台，治疗和灵魂支援。
形象：温和但疲惫的女性医者，穿白色、青绿色和灰蓝色的仪式服，服装像由布料和半透明灵魂丝线共同织成。
道具：引魂灯，灯中不是火焰而是一团温暖的青白色灵魂光；腰间挂有小药瓶、缝魂针和折叠符布。
动作：双手托起引魂灯，几条柔和的灵魂丝线从灯中连接向画面外的队友，表现治疗和保护。
主色：青绿、白、灰蓝、暖金。
气质：温柔、坚定、愿意承担他人痛苦。
画面要求：完整全身，引魂灯和灵魂丝线必须清晰，透明背景，光效不能遮住脸部和服装。

【图 5：四人初始队伍宣传构图】
文件名建议：party_initial_four_keyart.png
定位：角色选择界面和宣传图的四人队伍构图。
必须使用第 1～4 张角色作为一致性参考，不能重新设计四人的脸、服装和主要装备。
构图：
- 16:9 横向画面。
- 前排左侧是镇魇武者，手持裂纹长刃，承担保护队伍的姿态。
- 前排右侧是逐影猎手，拉弓瞄准远处的心魔。
- 后排左侧是织梦术士，托起橙红色梦火和漂浮书页。
- 后排右侧是引魂医者，举起青白色引魂灯。
- 四人围绕一枚悬浮的“回声锚点”，锚点由蓝色、紫色和暖金色的梦境碎片组成。
- 背景只保留深蓝梦雾、碎裂月亮、远处的梦境裂缝和少量漂浮光点。
- 中央和上方留出较干净的暗色空间，方便后续叠加游戏标题或界面文字，但本图不要主动生成任何文字。
氛围：四人刚刚进入濒临崩坏的梦层，既有危险感，也有短暂的同伴安全感。
画面要求：人物比例自然，四人都完整可见，前后层次清楚，不能互相遮挡武器和脸部。

输出检查：
请保证 5 张图的角色设计属于同一个游戏项目。
第 1～4 张必须是独立透明 PNG。
第 5 张必须能直接作为角色选择界面的队伍宣传图。
如果某张图出现文字、Logo、水印、拼图分格、重复人物、额外肢体或角色装备不一致，请重新生成该张，不要修改其他合格图片。
```
