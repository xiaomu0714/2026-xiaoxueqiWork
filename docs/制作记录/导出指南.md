# 导出网页版 / Windows 版操作指南

> 导出的目的是：网页版可以在浏览器里直接演示（答辩神器，无需安装任何东西）。

## 前置条件

1. 已经能正常按 F5 运行游戏（说明引擎 OK）
2. **联网下载导出模板**（一次性，约 500MB，需要网络）

## 第一步：下载导出模板

打开 Godot → 菜单 **编辑器（Editor）→ 管理导出模板（Manage Export Templates）**
→ 点 **下载并安装（Download and Install）**，等它下完（版本必须匹配你的 4.7.2）。

## 第二步：添加导出预设

1. 菜单 **项目（Project）→ 导出（Export）…**
2. 点 **添加…（Add…）** → 选择 **Web**（网页版）→ 保持默认设置，**导出路径**随意（默认 web/ 即可）
3. 再点 **添加…** → 选 **Windows Desktop**（Windows 版，可选，备用）

## 第三步：导出

- 网页版：导出面板选中 **Web** → 点 **导出项目（Export Project）** → 选择输出文件夹（建议 `D:\echo_dungeon_export\web`）
- Windows 版：选中 Windows Desktop → 导出 → 得到 exe（发给别人玩用）

## 第四步：验证网页版

导出后 `web/` 文件夹里有 `index.html` 和若干 `.wasm/.pck` 文件：
- **直接双击 index.html 可能打不开**（浏览器安全限制），正确做法：
  - 本地演示：装个简易静态服务器，或在 Godot 里按 F5 演示（等效）
  - 或上传到任意静态托管（如 GitHub Pages / 校园服务器 / Netlify）
- 答辩时最稳妥：**现场用 Godot 按 F5 演示** + 网页版作为可分发产物展示

## 常见问题

| 问题 | 解决 |
|---|---|
| 导出按钮灰色 | 导出模板没装好，重做第一步 |
| 网页打开白屏 | 需要用 http 服务访问（不能直接双击 index.html） |
| 想发给同学玩 | 用 Windows 导出，发 exe；或把 web 文件夹放内网服务器 |
