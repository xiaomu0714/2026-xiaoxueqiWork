# 《梦境回声》像素美术生图指令（精致Q版）

## 风格定位

**明日方舟小人 + 2D 像素**：约 2.5~3 头身，干净利落的轮廓，角色有设计感，表情偏冷静或内敛，
不卖萌不夸张。气质：精致、空灵、轻微忧伤、梦境般轻盈。**不恐怖、不血腥、不写实、不幼稚**。

## 统一生成规则

- 2D 像素美术；硬边像素轮廓；有限色板；不要 3D、厚涂、摄影感、柔焦。
- 底色：深邃蓝、灰紫、墨蓝；高光：暖金、青蓝、冷白、淡紫。整体色调偏冷、偏暗，但不压抑。
- 梦境感：漂浮微光粒子、薄雾、悬浮碎块、倒影、重复结构、细小的符文或几何纹样。
- 气质：**空灵、沉静、精致、略带疏离感**。像安静地站在梦里的感觉。
- 脸部：表情克制，不夸张大笑或大哭，眼神平静或微微忧郁。不要可爱颜文字式表情。
- 不要文字、数字、角色名、技能名、UI、Logo、水印。
- 输出 PNG；总表纯色底 #16162a，不要透明。
- 每张总表 2048×2048，固定网格，格间留明显空白。
- 资产不得跨格、互相遮挡或接触边界；每格四周留 24px 安全边距。

## 统一负面约束

""
不要文字、不要数字、不要标签、不要 Logo、不要水印、不要 UI、不要卡牌边框、不要拼图标题、

## 第一张总表：9 名角色（3×3）

### 角色设计（2.5~3 头身，精致像素，冷静克制）

**第一行：**

1. 镇魇武者 — 穿轻甲的青年剑士，肩部有护符，双手拄着一把大剑，站姿沉稳，表情平静。主色：藏蓝 + 暗金。
2. 逐影猎手 — 戴兜帽的弓箭手，侧身站立，手持短弓，箭袋在腰间，帽檐阴影遮住一只眼，嘴角微抿。主色：暗绿 + 灰银。
3. 织梦术士 — 穿拼接长袍的术士，法杖顶端有星芒，身边漂浮几枚符文碎片，目光看向远方。主色：深紫 + 月白。

**第二行：**

4. 引魂医者 — 提灯笼的医者，长围巾垂落，腰间挂药瓶，表情温和但不过度微笑，像在倾听。主色：灰白 + 青绿。
5. 梦盾守卫 — 持大盾的矮个守卫，盾面有几何纹样，头盔遮住上半张脸，站姿笔直可靠。主色：灰蓝 + 铜青。
6. 血梦刺客 — 围暗红围巾的轻装角色，双手低垂各持短刃，半张脸隐在围巾后，只露出一只冷静的眼。主色：暗红 + 黑。

**第三行：**

7. 灵脉乐师 — 怀抱竖琴的角色，衣摆如波纹，周围有细小的音符碎片，闭眼演奏。主色：青绿 + 象牙白。
8. 梦药炼金师 — 背药剂背包，手持发光试管，护目镜推在额上，表情专注，像在观察反应。主色：紫铜 + 淡金。
9. 裂梦剑客 — 持双剑的轻装剑士，身体微微侧倾，像随时要踏出残影，衣摆有裂纹纹样，眼神锐利但冷静。主色：银灰 + 暗紫。

## 第二张总表：9 种心魔（3×3）

心魔是负面情绪的具象化，**做成有设计感的幻想生物，不恐怖，也不幼稚**。

1. 暴怒 — 红色人形轮廓，身体有裂纹透出暗光，双拳紧握，低头，姿态压抑而非咆哮。像一座即将喷发的火山。
2. 嫉妒 — 紫色瘦长身影，身上缠绕着不属于自己的饰品和丝带，侧头斜视，手指细长。
3. 傲慢 — 高大石像，头戴碎裂王冠，胸膛挺起但闭着眼，身体表面有镜面反光。
4. 贪食幽光 — 漂浮的球状生物，中央有张开的大嘴，周围光点被缓缓吸入，身体半透明。
5. 疑惧蛛影 — 细长的多足剪影，腿的末端像墨迹晕开，身体中央有多只小眼睛，但整体是优雅的几何构成。
6. 守梦傀儡 — 木质人形，关节处有球形连接，胸口有发光的核心，站姿端正，像尽职的哨兵。
7. 缝梦医师 — 布偶人形，身上有整齐的缝线，手持针线，头微微歪着，表情空白但温柔。
8. 贪婪（精英） — 体型更大，身上堆叠着多层衣物和饰品，双手各抓着发光物件，姿态像在守护收藏。
9. 虚无（首领） — 体型最大，身体中央是一个深蓝色空洞，边缘有星环纹样，整体轮廓像一件空掉的袍子，没有面孔，安静地悬浮着。
