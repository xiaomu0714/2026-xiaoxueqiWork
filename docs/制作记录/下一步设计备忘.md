# 下一步设计备忘

这版 Demo 已改为“逐格选择节点 → 遭遇 → 获取/合成节点卡 → 成长 → 首领”的循环，并提供可操作的前后台资源与状态效果。

从 `个人设计思路.doc` 提取出的后续方向：

- 单层固定 13 个基础节点，包含 2 个精英与 1 个首领；开局可逐张选择路线顺序。
- 节点牌组已包含奇遇、镇守、奖励、招募、商店与恢复，并保留节点合成/升级扩展位。
- 战斗已支持前台输出（体力）+ 后台辅助（魔力）的两人队伍切换。
- 道具已分为独立使用的卷轴/药水与绑定角色的装备。
- 心魔已加入流血、晕眩两种状态，嫉妒与虚无会按回合施加。
- 世界观暂定为“入梦师进入梦境，击杀由负面情绪形成的心魔”。

推荐的下一轮讨论顺序：

1. 先定 3 个初始入梦师：定位、体力/魔力、核心技能。
2. 再定 5~6 种基础心魔与两个精英、一个首领的机制。
3. 最后把节点合成、装备槽位限制、连携技接入现有数据层。

当前可调数值集中在 `scripts/game_data.gd`，地图与单局状态在 `scripts/run_state.gd`。
