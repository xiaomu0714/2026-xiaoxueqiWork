# 《梦境回声》五张像素美术总表生图命令

## 这次的正确生成方式

这次不要让生图软件直接生成“5 张独立角色图”，而是生成 5 张“像素美术资产总表”：

- 每张总表都是一张 2048×2048 的像素素材集合图。
- 每个格子只放一个独立资产。
- 资产之间不能互相遮挡，格子之间留出明显空白。
- 我拿到图片后，会按固定行列裁成单张 PNG，再进行透明背景处理、缩放和 Godot 接入。
- 总表使用统一的深色纯色底，不要透明。纯色底更方便后续自动抠图和手动修边。
- 这 5 张图必须保持同一套像素颗粒、色板、描边、光照和梦境风格。

如果软件支持“一次生成 5 张”，请把下面的“五张总表规划”作为同一个任务提交，并要求“输出 5 张不同内容的总表”。  
如果软件不支持按不同内容生成 5 张，请分别复制“总表 1”到“总表 5”，各生成一张。

## 五张图的分工

| 总表 | 内容 | 建议网格 | 主要用途 |
|---|---|---:|---|
| 总表 1 | 8 名角色 | 4×2 | 角色选择、战斗卡、招募、装备界面 |
| 总表 2 | 9 种心魔 | 3×3 | 普通战斗、精英、Boss |

| 总表 4 | 12 个奇遇场景 | 4×3 | 奇遇事件界面和连续事件 |
| 总表 5 | 22 件物品 + 8 类节点图标 | 6×5 | 装备、消耗品、节点卡和资源 UI |

把下面这段放在每一张总表的提示词开头：

```text
Use case: stylized-concept
Asset type: 2D pixel-art game asset sheet for a turn-based roguelike dream adventure game
Input image: the uploaded PNG is a STYLE REFERENCE ONLY. Use it only for pixel density, palette, lighting, texture, mood, and rendering language. Do not copy its exact characters or composition.

请制作《梦境回声》的像素美术资产总表。
这是一个梦境题材 2D 回合制肉鸽游戏：入梦师进入正在崩坏的集体梦境，净化由暴怒、嫉妒、傲慢、疑惧等负面情绪形成的心魔，救出梦魂，并沿着逐步生成的梦境航线探索。

核心美术风格：
- 主 2D 像素美术，不是 3D 渲染，不是普通厚涂插画。
- 清晰像素颗粒、硬边像素轮廓、有限色板、低饱和深蓝和灰紫基底。
- 局部使用暖金、青蓝、青绿色、暗红和紫红高光。
- 梦境感来自漂浮碎片、半透明雾、错位影子、裂缝、重复结构和微小符文。
- 气质诡异、忧伤、华丽、空旷、带轻微童话感；不要写实恐怖，不要血腥。
- 保持统一的像素比例、统一的光照方向、统一的描边粗细和统一的阴影颗粒。

总表排版规则：
- 画布固定为 2048×2048。
- 使用规则网格排版，每格只放一个资产。
- 每个资产必须完整显示，不得超出自己的格子，不得与邻格接触。
- 格子之间保留明显的空白分隔，方便后续裁切。
- 每个资产四周保留至少 24 像素安全边距。
- 所有格子的背景使用同一种纯色深蓝：#111827；不要透明。
- 不要生成任何文字、数字、名称、标签、UI 文案、Logo、水印。
- 不要生成拼图边框，不要生成装饰性标题，不要把多个资产合成一件物体。
- 不要反锯齿，不要柔焦，不要摄影感，不要 3D 材质。
- 输出必须是整齐的像素资产总表，而不是自由散落的概念画。
```

## 重要提醒

- 这次的重点不是让生图软件识别中文标签，而是让它按照“固定网格 + 固定顺序”生成。
- 不要要求软件在图中写角色名字，否则文字会变形并影响裁切。

- 如果某一格效果不好，优先只重生成对应的整张总表，不要让软件改变网格顺序。
- 五张图都要使用同一张 PNG 作为风格参考，确保最终项目像同一款游戏。
