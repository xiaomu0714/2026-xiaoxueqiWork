# 《梦境回声》生图执行清单

这份清单用于把当前 Demo 的美术占位替换成统一的像素美术资源。

## 当前项目的真实资产范围

以 `README.md` 和《美术制作需求清单》为准，第一阶段先做：

- 8 名入梦师：4 名初始角色 + 4 名可招募角色
- 9 种心魔：7 种普通/治疗型心魔 + 1 名精英 + 1 名首领

## 统一生成规则

上传项目中的 PNG 风格参考图：

`D:\deepseek\work1\1231_8d0371574bd340f992c87d3f7357e02c_1787922491948.png`

只把它作为像素密度、色板、描边、光照和氛围参考，不复制其中的具体人物或构图。

统一要求：

- 2D 像素美术；硬边像素轮廓；有限色板；不要 3D、厚涂、摄影感或柔焦。
- 基底色为深蓝、灰紫、墨黑；高光使用暖金、青蓝、青绿色、暗红和紫红。
- 梦境感来自漂浮碎片、半透明雾、错位影子、裂缝、重复结构和微小符文。
- 气质诡异、忧伤、华丽、空旷，带一点童话感；不要写实恐怖和血腥。
- 不要文字、数字、角色名、技能名、UI、Logo、水印。
- 输出 PNG；总表使用纯色深蓝底 `#111827`，不要透明。
- 每张总表 2048×2048，固定网格，每格一个资产，格间留明显空白。
- 资产不得跨格、互相遮挡或接触边界；每格四周至少留 24 像素安全边距。

## 生图网站操作策略

1. 先生成总表 1 和总表 2，确认角色/心魔风格一致后再继续。
2. 每次只生成一张总表，避免网站把不同提示词混成一张拼图。
3. 生成后保留原始 PNG，不要先转 JPG、压缩或在网站内裁切。
4. 如果某一格不合格，记录“总表编号 + 行列位置”，只重做对应总表。
5. 将 5 张原始总表 PNG 放到：

`D:\deepseek\work1\echo_dungeon\art\source_sheets\`
