# 《梦境回声》美术制作需求清单

> 这份文档用于直接提供给角色原画、UI、场景和特效美术。  
> 当前 Demo 使用色块和文字占位，以下资产将逐步替换占位内容。

## 一、项目定位

《梦境回声》是一款梦境题材的 2D 回合制肉鸽探索游戏。

玩家扮演“入梦师”，进入濒临崩坏的集体梦境，沿着一条不断生成的梦境航线前进，净化由人类负面情绪形成的“心魔”，救出失联的梦魂，并在每次选择中决定继续深入、获取资源，还是承担更大的梦蚀风险。

游戏的核心感受：

- 梦境不稳定：空间、建筑、人物和记忆会发生错位、重复、倒悬、融化。
- 情绪具象化：敌人不是普通野兽，而是暴怒、嫉妒、傲慢、疑惧等情绪形成的心魔。
- 选择有代价：安全离开、未知尝试、角色/装备洞察，三种选择带来不同信息量和风险。
- 逐步构筑：玩家不是开局规划完整地图，而是边探索边从节点卡组放置路线。
- 战斗重策略：前台承伤与后台支援分工，体力、魔力、护盾、流血、晕眩、蓄力和队伍联动共同构成战术。

## 二、统一美术方向

### 关键词

梦境、空旷、静谧、压迫、碎片化记忆、低饱和冷色、局部高亮、情绪具象化、半透明叠层。

### 建议风格

- 2D 半厚涂 / 轻赛璐璐均可，但同一批资产必须统一。
- 现实物件作为基础，叠加不合逻辑的梦境变化。
- 背景以深蓝、灰紫、墨黑为主；正向资源用暖金、青蓝、青绿色强调。
- 敌人使用红紫、暗红、病态蓝等高对比色，体现“情绪污染”。
- 不要做成纯恐怖血腥风，更接近“诡异、忧伤、华丽、带一点童话感”的梦境冒险。
- 角色轮廓必须清楚，缩小到战斗卡片尺寸后仍能辨认职业和主色。

### 当前技术画布

- 游戏逻辑画布：1280×800。
- 常用显示窗口：1920×1200。
- 角色、敌人和道具建议提供透明 PNG。
- UI 图标建议提供 128×128 和 256×256 两档。
- 立绘建议至少 2048px 高度；战斗小人/半身像建议 512×512 或 1024×1024。
- 场景背景建议 2560×1600 或更高，保留安全裁切区域。
- 文件格式：PNG；需要可编辑源文件时提供 PSD/KRA/CLIP/AI。
- 每个资产请同时提供：带透明背景版本、预览 JPG、命名清晰的源文件。

## 六、节点卡与 UI 资产

节点卡是游戏的主要构筑资源。开局随机 6 张，之后通过战斗、奖励和奇遇补充。

### 节点卡类型

- 镇守：红色，剑刃/心魔图形。
- 奇遇：蓝紫色，眼睛/门/裂缝图形。
- 奖励：金橙色，梦匣/宝石图形。
- 招募：青绿色，锚点/人形剪影图形。
- 商店：金黄色，交易印记/货箱图形。
- 恢复：绿色，月牙/泉水图形。
- 精英：紫红色，王冠/裂纹图形。
- 首领：深红黑色，空洞核心/巨大眼睛图形。

### 节点卡需要的状态

- 普通、悬停、选中、不可选、已使用。
- Lv.1、Lv.2、Lv.3 的等级边框差异。
- 三张同类型同等级合成时的融合动效和结果卡。
- 获得卡牌、放置卡牌、卡组为空/不足时的提示图标。

## 七、装备与消耗品图标

当前共有 22 件物品。建议统一为正方形图标，图标本体清晰、背景透明，稀有度用边框区分。

### 消耗品

1. 微光药剂：小瓶、青绿色液体，回复生命。
2. 浓缩梦露：更大的紫蓝色瓶，回复大量生命。
3. 醒神茶：冒着蒸汽的茶杯，回复体力。
4. 星辉墨水：装有星光的墨水瓶，回复魔力。
5. 梦火卷轴：燃烧的橙红卷轴，直接伤害。
6. 猩红梦针：红色针具，造成流血。
7. 惊雷符：带闪电纹样的符纸，造成晕眩。
8. 守梦晶球：蓝色晶球，获得护盾。
9. 净心香：青白色香炉或线香，净化负面状态。
10. 破梦炸弹：裂纹球体，造成高额伤害。

### 装备

1. 怒痕长刃：击杀后回复体力。
2. 月纹法杖：提高魔力和法术伤害。
3. 逐影长弓：提高体力，对流血目标增伤。
4. 护梦披风：提高生命/魔力，支援返还魔力。
5. 镇魇重甲：提高生命、减伤和护盾收益。
6. 织梦长袍：提高生命/魔力，过量治疗转护盾。
7. 暴怒护符：低生命时提高伤害。
8. 回声指环：提高魔力和消耗品效果。
9. 守夜徽章：提高生命，战斗开始获得护盾。
10. 逐梦行靴：提高体力，第一次行动减费。
11. 血契面具：提高攻击，施加流血时增加层数。
12. 引魂灯：提高治疗，净化时额外提供护盾。

## 八、场景背景清单

### 必做主场景

1. 标题界面：深蓝梦海、远处破碎月亮、中央梦境裂缝。
2. 角色选择界面：四个初始角色站在梦境锚点前。
3. 梦境航线地图：悬浮道路、节点卡、远处精英门和首领门。
4. 战斗场景：上方敌方、下方我方，中间留出技能和意图区域。
5. 战前装备界面：装备台、悬浮装备槽、角色剪影。
6. 奇遇界面：中央事件物件、三项选择按钮、暗色留白。
7. 奖励界面：梦匣、祭台、宝库、三项奖励卡。
8. 招募界面：回声锚点、四道候选意识信号。
9. 商店界面：梦境商贩、漂浮货架、金币和物品。
10. 结算界面：梦境崩塌或暂时平静的远景。

### 奇遇专属场景

每个奇遇至少需要一张横向事件插画，画面中心留出文字区域，左右或下方留出选项区域。

## 九、12 个奇遇事件的美术简报

### 1. 迷途商队

梦雾中的商队停在道路边，货箱自行震动。安全选项是离开；打开货箱可能得到药剂和金币、良性节点卡，也可能触发嫉妒战斗；拥有回声指环可以听出真正的宝箱。

画面重点：歪斜货车、半透明商人、封闭货箱、雾中若隐若现的紫色眼睛。

### 2. 裂纹镜厅

镜中倒影与玩家动作不一致。触碰镜面可能得到攻击成长、流血负面或触发傲慢战斗；织梦术士可以识破安全镜面并获得梦火卷轴和 Lv.2 奖励节点卡。

画面重点：多面镜子、错位倒影、镜后伸出的手、碎裂的空间。

### 3. 梦果园

树上结满颜色不同的梦果，普通人无法判断成熟度。品尝后可能获得生命/经验、净心香，或承受掉血和流血；逐影猎手可以直接辨认成熟果实。

画面重点：漂浮果园、发光果实、树根扎入云雾、果实内部的微型梦境。

### 4. 回声图书馆

书页自动翻动，其中一些文字被心魔篡改。阅读可能得到攻击成长、梦火卷轴和良性节点卡，也可能失去魔力并晕眩；术士或回声指环可以校正目录并获得月纹法杖。

画面重点：无尽书架、漂浮书页、错误文字、会回头的书脊。

### 5. 无名守门人

守门人要求队伍证明勇气，却不说明试炼内容。接受试炼可能获得金币、体力成长，或触发精英战；镇魇武者或镇魇重甲可以正面承受梦压。

画面重点：巨大门扉、没有脸的守门人、门缝中的红光、脚下逐渐升高的压力波纹。

### 6. 遗忘车站

广播不断念出队伍成员忘记的名字，远处列车缓慢进站。玩家可能获得记忆残片、梦蚀和 Lv.2 奖励卡，也可能与检票员梦魇战斗；灵脉乐师可以找到安全记忆。

画面重点：无时钟月台、苍白车灯、广播喇叭、被雾遮住的列车终点牌。

### 7. 驶向无名之梦的列车

这是遗忘车站的连续事件。列车窗内坐着无数个没有面孔的“自己”。玩家可以烧掉车票、支付记忆寻找真实车厢，或由梦盾守卫强行救出梦魂；成功路线可获得 Lv.2 招募节点卡。

画面重点：列车内部重复的座位、无脸乘客、车窗外倒退的梦境、唯一有姓名的车厢。

### 8. 沉睡剧院

舞台正在重演梦魂最痛苦的记忆，观众都戴着与玩家相同的面具。代替梦魂演出可能得到记忆、生命成长、金币和装备，也可能积累梦蚀并触发多敌人战斗；血梦刺客可以切断幕后血线。

画面重点：红色幕布、面具观众、舞台聚光灯、从地板伸出的黑色血线。

### 9. 倒悬病房

病床固定在天花板，心电图记录的是梦境本身的脉搏。读取病例可能获得记忆和攻击、生命成长，也可能触发梦魇战斗；梦药炼金师可以分析梦蚀成分并制作稳定药剂。

画面重点：倒悬病床、天花板上的输液瓶、上下颠倒的阴影、异常心电图。

### 10. 层叠梦井

井水倒映出更深一层梦境，投入记忆后可能获得装备、Lv.2 奖励卡或触发战斗；织梦术士可以稳定梦层并获得 Lv.3 奖励节点卡。

画面重点：看不见底的井口、层层叠叠的倒影、垂直落下的星光、井底睁开的眼睛。

### 11. 伪醒公寓

玩家在熟悉的房间中醒来，却发现窗外仍是梦境，每次开门都会回到同一张床上。玩家可以等待、尝试打破循环，或承受梦蚀后与“另一个自己”战斗；回声指环和灵脉乐师可以验证现实。

画面重点：重复的卧室门、床上叠着多个自己、窗外不合理的城市、时钟指针倒转。

### 12. 记忆拍卖会

无脸宾客用童年、姓名和遗憾竞拍梦中遗物，只接受真正属于玩家的记忆。玩家可以旁观、交出记忆盲拍，或让梦药炼金师鉴定真伪；高收益路线可获得 Lv.2/Lv.3 招募节点卡。

画面重点：无脸宾客、悬浮拍卖台、被玻璃封存的记忆片段、举牌的手。

## 十、特效清单

### 战斗基础特效

- 普通攻击：武器挥击、箭矢、法术弹道。
- 受击：短促闪白、色块碎裂、梦屑飞散。
- 死亡：身体裂开并化为粒子，不建议使用写实血液。
- 护盾：半透明蓝色/青色圆弧或晶体层。
- 流血：红色细线、滴落的梦境液体、血痕叠层。
- 晕眩：头顶旋转符号、断续星光。
- 治疗：绿色/青色灵魂丝线回流。
- 魔力恢复：蓝紫色音符或星屑。
- 体力恢复：橙黄色脉冲。
- 蓄力：角色脚下法阵、逐渐收缩的环、屏幕边缘轻微震动。
- 多目标技能：横向波纹、全场裂纹或扇形扩散。
- Boss 二阶段：场景降暗、背景裂缝扩大、核心变色、随从强化。

### 节点与资源特效

- 节点卡获得：卡片从梦境裂缝中翻出。
- 节点卡放置：卡片化为场景门扉。
- 三合一：三张卡旋转、叠合、爆发为高等级卡。
- 探索升级：经验条满后出现环形扩散和等级徽记。
- 梦境压力提升：地图边缘变暗，精英/首领节点出现额外紫红脉冲。
- 梦蚀增加：画面短暂出现黑色噪点和错位重影。

## 十一、UI 组件清单

- 标题 Logo：“梦境回声”。
- 节点卡牌框、等级角标、类型图标。
- 角色头像框、前台/后台标记。
- 生命、体力、魔力三种细资源条。
- 敌人意图图标和目标指示器。
- 装备槽、背包格、消耗品按钮。
- 金币、探索经验、梦境压力、梦蚀、记忆残片图标。
- 技能按钮、蓄力状态、行动完成状态。
- 查看详情弹窗、分页标签、关闭按钮。
- 奖励品质边框：普通、精良、稀有、梦魇、传说。
- 通用按钮：普通、悬停、按下、禁用、危险操作。

## 十二、交付验收标准

1. 同一角色的立绘、头像、战斗姿态和技能特效必须保持脸部、服饰、主色一致。
2. 角色缩小到 218×106 左右的战斗卡片时，仍能一眼区分前台/后台和职业。
3. 敌人缩小到战斗卡片时，仍能区分不同情绪。
4. 所有图标不依赖文字才能看懂大致功能。
5. 场景必须保留文字和按钮安全区，不能把高对比细节放在 UI 文字底下。
6. 特效必须提供“轻量版”和“完整表现版”两个强度档，方便后续性能优化。
7. 动画如果暂时来不及，可以先交静态关键帧、序列帧和特效分层图。
8. 文件命名建议统一为：
   - `char_warrior_portrait.png`
   - `enemy_rage_idle.png`
   - `item_rage_blade.png`
   - `event_dream_orchard_bg.png`
   - `fx_blood_apply_01.png`

## 十三、建议给美术的制作顺序

第一批：4 名初始角色 + 9 种敌人 + 战斗背景 + 资源/状态图标。  
第二批：4 名可招募角色 + 节点卡全套 + 装备/消耗品图标。  
第三批：12 个奇遇背景 + 奖励/招募/商店/装备/结算背景。  
第四批：技能动画、Boss 二阶段、连续奇遇过场和宣传图。
